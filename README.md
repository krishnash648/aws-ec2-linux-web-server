\# AWS EC2 Linux Web Server with Nginx



This project demonstrates deploying a Linux web server on AWS EC2 using Nginx.



\## Technologies Used

\- AWS EC2 (t3.micro)

\- Amazon Linux 2023

\- Nginx

\- SSH (key-based authentication)



\## What I Did

\- Launched an EC2 instance

\- Configured security groups (SSH \& HTTP)

\- Connected via SSH using key pair

\- Installed and configured Nginx

\- Deployed a custom HTML web page

\- Fixed UTF-8 encoding issue
